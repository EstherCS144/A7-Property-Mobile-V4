# A7 Property Brand System

The implemented brand contract is now frozen in [A7 Property Design System v1](./design-system.md).

A7 Property uses deep navy (`#123B73`), cobalt accent (`#4DA3FF`), pale-blue canvas (`#EAF4FF`), cool-white surfaces (`#F8FBFF`), and dark ink (`#101828`). The supplied A7 mark, Myanmar-first Z06 Walone typography, natural property photography, and selective transparent 3D journey assets form the recognizable brand language.

This companion file no longer defines alternate colors or typography. `app/globals.css` and `docs/design-system.md` are the implementation and governance sources of truth.
